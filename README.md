# Sales Performance Dashboard using Power BI

## Project Overview
An interactive Sales Performance Dashboard created using Power BI to analyze sales performance and generate meaningful business insights.

## Tools Used
- Power BI
- DAX
- Excel / CSV

## Key Features
- Total Sales KPI
- Total Orders KPI
- Total Quantity KPI
- Average Order Value
- Total Profit
- Category-wise Sales Analysis
- Product-wise Sales Analysis
- Region-wise Sales Analysis
- Monthly Sales Trend
- Interactive Category and Region Slicers

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- DAX
- Data Visualization
- Dashboard Development
